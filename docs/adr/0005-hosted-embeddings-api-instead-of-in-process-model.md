# Hosted embeddings API (Voyage AI) instead of an in-process local model

Supersedes ADR-0003. The deployment target changed to Vercel + Neon (both free-tier), and Vercel's Python functions cap at 500MB uncompressed bundle size — sentence-transformers plus its torch dependency blow past that limit, so the embedding step can no longer run in-process inside the FastAPI app. Embeddings are now generated by a hosted embeddings API instead.

Voyage AI was picked over Cohere and Google Gemini embeddings on free-tier terms: Cohere's trial key is capped at 1,000 API calls/month, too low for a widget answering live shopper questions; Gemini's embeddings are free but Google's own docs don't publish a rate-limit ceiling to plan against. Voyage AI's free tier is 200 million tokens per account with no monthly call cap, and this is documented directly in Voyage's pricing docs.

**Consequences**: embedding now requires a network call and an API key (a new external dependency and a new failure mode ADR-0003 explicitly avoided); sync and request-time embedding both depend on Voyage's uptime and rate limits. Switching models later still just means re-running the full resync (ADR-0002), but now also means picking a new provider/API, not just a new local checkpoint.
